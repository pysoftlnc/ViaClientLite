# Version Spoofer Mod

Мод для Fabric (версия загрузчика 0.19.5, Minecraft 1.19.2), который добавляет возможность подмены версии клиента при подключении к серверам.

## Возможности

- **Перетаскиваемая кнопка** в меню серверов для быстрого доступа
- **Выбор версии** из широкого диапазона:
  - Старые версии: от 1.7.10 до 1.16.5
  - Современные версии: от 1.17.1 до 1.21.11
  - Будущие версии: 26.1, 26.1.1, 26.1.2, 26.2, 26.3
- **Индикатор текущей выбранной версии** в списке
- **Сохранение позиции кнопки** между сессиями

## Установка

1. Установите [Fabric Loader](https://fabricmc.net/use/installer/) версии 0.19.5 или выше
2. Установите [Fabric API](https://modrinth.com/mod/fabric-api) для Minecraft 1.19.2
3. Скопируйте файл `.jar` мода в папку `mods` вашего экземпляра Minecraft
4. Запустите игру

## Использование

1. Откройте меню "Multiplayer" (Сетевая игра)
2. Найдите перетаскиваемую кнопку "Select Version" в углу экрана
3. Перетащите кнопку в удобное место (опционально)
4. Нажмите на кнопку, чтобы открыть меню выбора версии
5. Выберите нужную версию из списка
6. Подключайтесь к серверам - они будут видеть выбранную версию

## Важные замечания

- Подмена версии не гарантирует совместимость со всеми серверами
- Некоторые серверы могут использовать дополнительные проверки
- Мод работает только на стороне клиента

## Сборка

```bash
./gradlew build
```

Собранный файл будет находиться в `build/libs/`
