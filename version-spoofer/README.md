# Version Spoofer - Fabric Mod (1.19.2 - 26.3)

Мод для подмены версии клиента при подключении к серверам Minecraft.

## Возможности

- **Перетаскиваемая кнопка** в меню серверов для выбора версии
- **Поддержка версий от 1.16.5 до 26.3** (включая все промежуточные версии)
- **Автоматическая подмена протокола** при подключении к серверу
- **Простой интерфейс** выбора версии

## Поддерживаемые версии

### Старые версии
- 1.16.5, 1.17, 1.17.1, 1.18, 1.18.1, 1.18.2, 1.19, 1.19.1, 1.19.2

### Версии 1.20.x
- 1.20, 1.20.1, 1.20.2, 1.20.3, 1.20.4, 1.20.5, 1.20.6

### Версии 1.21.x
- 1.21, 1.21.1, 1.21.2, 1.21.3, 1.21.4, 1.21.5, 1.21.6, 1.21.7, 1.21.8, 1.21.9, 1.21.10, 1.21.11

### Будущие версии 26.x (2026)
- 26.1, 26.1.1, 26.1.2, 26.2, 26.3

## Установка

1. Установите [Fabric Loader](https://fabricmc.net/use/installer/) версии 0.19.5 или выше
2. Установите [Fabric API](https://modrinth.com/mod/fabric-api)
3. Скопируйте файл `.jar` мода в папку `mods` вашего Minecraft
4. Запустите игру с профилем Fabric

## Использование

1. Откройте меню серверов (Multiplayer)
2. Найдите кнопку "Version" в правом верхнем углу
3. Перетащите кнопку в удобное место (опционально)
4. Нажмите на кнопку для открытия меню выбора версии
5. Выберите нужную версию из списка
6. Подключитесь к серверу - он будет видеть выбранную версию

## Сборка

```bash
./gradlew build
```

Собранный файл будет находиться в `build/libs/`

## Примечания

- Мод работает только на стороне клиента
- Для корректной работы требуется совместимость протоколов между версиями
- Некоторые функции сервера могут быть недоступны при использовании несовместимых версий
